# 📊 Market Analyzer

Analyse automatique des marchés crypto et forex en temps réel.

## 🚀 Fonctionnalités

- **Analyse Crypto**: Bitcoin, Ethereum, BNB, Cardano
- **Analyse Forex**: EUR/USD, GBP/USD, USD/JPY, AUD/USD
- **Signaux Automatiques**: BUY/SELL générés en continu
- **Rapports de Tendance**: Analyse du sentiment global du marché
- **Mise à jour**: Toutes les 5 minutes

## 🛠️ Technologie

- Frontend: HTML5, CSS3, JavaScript vanilla
- APIs: Binance (crypto), Alpha Vantage (forex)
- Hosting: Vercel (frontend) + Render (backend optionnel)

## 📈 Comment ça marche

1. Récupère les données des APIs publiques gratuites
2. Analyse avec moyennes mobiles (MA5, MA20)
3. Génère des signaux BUY/SELL
4. Affiche les résultats en temps réel

## 🆓 Gratuit à 100%

- Code open source
- APIs gratuites
- Hosting gratuit

## 📝 Utilisation

1. Clone le repo
2. Ouvre `index.html` dans un navigateur
3. Attends la première analyse (quelques secondes)
4. Les signaux se mettent à jour automatiquement

## ⚠️ Disclaimer

Ce projet est à titre informatif. Ne pas utiliser comme seule base de décision trading. Les marchés sont imprévisibles.
